# Конфиденциальность llamur

Версия 0.4.0-dev, 26 октября 2026 года. Эта политика описывает подготовленное
приложение, а не обещания сторонних провайдеров или будущих версий.

## Переписка и локальный запуск

По умолчанию выбран режим «Никогда не сохранять». Временные диалоги, их черновики
и ответы находятся только в RAM процессов llamur и исчезают после завершения
процесса модели. Сворачивание само по себе их не удаляет.

При явном выборе постоянного диалога и разрешении хранения переписка, черновик,
закрепления, название и служебное reasoning-состояние сохраняются в приватной
SQLite-базе. Содержимое и каталог зашифрованы AES-GCM случайным ключом данных,
обёрнутым ключом AndroidKeyStore. Снаружи зашифрованных записей остаются случайные
идентификаторы, размеры и сроки удаления. Credentials в историю не включаются.
Настройки хранения и папки сохраняются отдельно зашифрованно, даже когда
переписки временные. Постоянную историю можно удалить по одному диалогу либо
переключением в «Никогда не сохранять» с подтверждением. Уже загруженное в RAM
содержимое при таком переключении остаётся временным; не загруженные записи
исчезают из списка. После потери ключа данные не удаляются автоматически.

Автоудаление постоянных чатов выбирается на 1 час, 24 часа, 7 или 30 дней от
последней активности. Активный ответ сначала завершается. Android может задержать
нестрогий фоновый alarm, а после перезагрузки очистка возобновляется при следующем
запуске/доступе: точное время физического стирания не обещается. Сохраняются приём
запроса, завершение, черновики и явные изменения; каждый токен отдельно не пишется.
При гибели службы незавершённый ответ помечается прерванным и не отправляется
повторно. При ошибке записи полный живой ответ остаётся в RAM с предупреждением.

Выбранные через «+» вложения не копируются в незашифрованный кэш. Неотправленные
вложения находятся только в RAM интерфейса. После отправки они входят в историю
с тем же режимом хранения: RAM временного чата или зашифрованная запись
постоянного. По API содержимое отправляется выбранному провайдеру; локально
поддерживается только текст UTF-8. При смене источника пустого диалога вложения
черновика убираются с уведомлением; исходные файлы не меняются.
Явное «Сохранить файл» создаёт обычный файл в месте, выбранном в системном
проводнике. Такая экспортированная копия уже не относится к зашифрованной истории.

Закрытие/удаление диалога и secure_delete SQLite не являются гарантией немедленного
стирания всех копий на flash, в swap или аварийной диагностике Android.

Локальный ответ вычисляется на телефоне. Приложение не отправляет запросы или
ответы разработчику, не содержит аналитики, рекламы, телеметрии или облачного
резервного inference. Резервное копирование данных приложения Android отключено.
Автосохранение текста полей и персонализированное обучение IME для чата отключены;
сторонняя клавиатура, системная служба специальных возможностей, пользовательский
скриншот и другие программы подчиняются собственным настройкам и политикам.

Кнопка «Копировать» помещает выбранный текст в системный буфер обмена. Это явное
действие пользователя; дальнейшее поведение буфера контролирует Android.
Уведомление «Ответ готов» не содержит запроса, ответа или названия диалога.
Нажатие открывает доступный временный или сохранённый постоянный диалог. Если он
удалён либо временная память исчезла, показывается ошибка; запрос не повторяется.

## Что сохраняется

На диске остаются выбранные настройки/профили, реестр моделей, имена/размеры/
контрольные суммы/источники файлов, разрешения на подключённые документы,
метаданные и частичные файлы незавершённых загрузок. Сами модели сохраняются
как файлы. На Android10+ новые управляемые файлы находятся в
**Downloads / llamur / Models**; это видимое хранилище, которое может быть
доступно другим программам согласно разрешениям Android. На Android9 используется
приватное хранилище. Подключённый без копии документ остаётся у своего провайдера.

Разработческие instrumentation/benchmark-сценарии в тестовой debuggable-сборке
могут отдельно сохранять публичные тестовые запросы, результаты и диагностику.
Они не являются режимом обычного чата и отключены для non-debug release.
Результат вручную запущенной диагностики возможностей может храниться в приватном
файле приложения; он не отправляется разработчику автоматически.

## Hugging Face и сетевой API

Для загрузки пользователь обращается к Hugging Face и его инфраструктуре доставки
через HTTPS. Провайдер получает обычные данные сетевого запроса, включая IP,
выбранный repo/revision/file и credential при аутентификации. На них распространяется
[политика Hugging Face](https://huggingface.co/privacy). HF token необязателен;
по умолчанию он находится в RAM. По отдельному выбору сохраняется за AndroidKeyStore
AES-GCM и удаляется кнопкой «Забыть». Bearer не пересылается CDN по редиректу.

OpenAI-compatible API выключен по умолчанию. При включении он принимает содержимое
запроса от клиента и возвращает ответ этому клиенту; сторонний клиент может сам
сохранять переписку. Loopback HTTP требует случайный API Bearer; доступ по Wi-Fi
требует отдельного включения, TLS и Bearer. API token отличается от HF token.
API Bearer живёт только в RAM текущего сервера; приватный TLS-ключ
остаётся в AndroidKeyStore. Публичный сертификат можно экспортировать. API не ведёт журнал тел запросов/credentials и не
сохраняет клиентскую историю. Не публикуйте token или API в Интернет.

## Внешние провайдеры по явному выбору

Подключение OpenRouter/OpenAI/Anthropic или другого endpoint передаёт историю
выбранного удалённого диалога, системную инструкцию, model ID, параметры и
credential этому серверу. Сервер видит IP и сетевые метаданные; его собственная
политика хранения и условия аккаунта действуют независимо от llamur. `store:false`
в native OpenAI не является обещанием zero retention. Локальные диалоги туда
автоматически не переносятся; облачного fallback при ошибке/нехватке памяти нет.

История, частичные ответы и подписанное/зашифрованное reasoning-состояние остаются
в RAM временного диалога либо в зашифрованном хранилище выбранного постоянного. Конфигурация подключения и активные model IDs
сохраняются. Ключ/дополнительные заголовки по умолчанию в RAM процесса сервиса;
по отдельному выбору шифруются AES-GCM за собственным AndroidKeyStore alias.
Удаление подключения удаляет его сохранённые credentials; «Забыть» очищает прежние
ключ и заголовки. Они не возвращаются в интерфейс или клиентам локального API,
не выводятся в логи. Redirection отклоняется, автоматических платных повторов нет.
HTTPS проверяется стандартными средствами Android. HTTP к произвольному серверу
разрешается после предупреждения и явного согласия для конкретного адреса в
настройках подключения. Сообщения, файлы и credentials не защищены самим HTTP;
VPN/Tailscale должен обеспечивать защиту отдельно. Приложение не проверяет маршрут
VPN. HTTP-подключения отмечены знаком ⚠ в интерфейсе. Подробнее: [внешние провайдеры](providers.md).

## Сводки контекста

Ручное сжатие и явно включённый автокомпакт используют модель текущего диалога.
Автокомпакт по умолчанию выключен. Для API это дополнительные обращения к тому
же провайдеру с ранней перепиской/вложениями и предыдущей сводкой, по его условиям
и тарифу. Облачного сжатия локальных диалогов нет. Скрытые рассуждения не включаются
в текст для пересказа. Исходная история не удаляется: оригинал, предпросмотр и
активная сводка следуют режиму временного/постоянного чата и его автоудалению.
Сводку можно прочитать и отменить; она может упустить детали. Остановка/перезапуск
не запускает повторный запрос. Подробнее: [сжатие контекста](providers.md#сжатие-контекста-локально-и-по-api).

## Управление данными и разрешения

В менеджере места можно удалить управляемую модель или незавершённую загрузку,
либо отключить внешний файл без удаления исходника. Удаление исходника после
импорта требует отдельного явного согласия и повторной проверки SHA. Возможное
облачное удаление через document provider выполняет выбранный провайдер.
Удаление приложения очищает его приватные данные, но файлы в Downloads и внешние
документы могут остаться — удалите их отдельно при необходимости.

Уведомления можно запретить в Android. Foreground service и временный wake lock
используются для явно запущенной генерации/загрузки; работу можно остановить.
llamur не запрашивает доступ к контактам, микрофону, камере или управление телефоном.
Интернет нужен для HF, явно выбранных внешних провайдеров и включённого API; локальный чат работает offline.

Публичный контакт сопровождающего и URL политики будут закреплены владельцем
перед публикацией. Подготовка исходников не означает публикации или принятия F-Droid.
