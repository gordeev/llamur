# llamur0.6.6 — Reproducible Linux preview

This release source sets versionCode 14, preserving the public 0.6.5 signing
identity, Android 9+/ARM64 support and existing application features.

- Release checkout VCS metadata is disabled.
- Native source and NDK paths are normalized; llama build identity is pinned to
  the upstream lock instead of the surrounding app's Git history.
- Compilation remains build-tools 36.1.0; release signing uses apksigner 34.0.0
  for F-Droid signature-copy compatibility.
- Updated English/Russian store descriptions, real screenshots and F-Droid recipe.

Original model weights, runtime code, numerical patches and generation defaults
are unchanged. Existing published performance results retain their original APK
hashes; this packaging release does not claim newly measured throughput gains.

The actual two-build Linux reproducibility result, APK hash, source commit and
signature checks are published in the release assets and in
`docs/releases/0.6.6-verification.json` on the public main branch after testing.
The source freeze does not itself certify a future build. No F-Droid submission
or official F-Droid server acceptance is claimed.
