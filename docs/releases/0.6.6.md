# llamur 0.6.6 — Reproducible Linux preview

Download **llamur-0.6.6-arm64-v8a.apk** from Assets. Requires **Android 9+ and a
64-bit ARM64 OS**. Model weights are downloaded separately.

Normal updates from the public GitHub **0.6.5 preserve app data**: this APK uses
the same release certificate. Uninstalling is unnecessary for that update.
Older local Android Debug builds use another signer; keep any data you need.

## Changes and verification

- Two fresh offline Linux release+lint builds from the same source commit,
  with different project/SDK/NDK paths and Git presence, produced **byte-identical unsigned APKs**.
- The signed APK verifies against **both** builds through apksigcopier.
  Compilation uses build-tools 36.1.0; signing uses apksigner 34.0.0.
- Checkout-dependent Git metadata and native paths are removed/normalized.
- 80 Python tests passed; APK/ELF 16 KiB/permissions/notices audit and F-Droid
  source/binary scanners passed. Native checks: 81 passed, 27 unsupported optional
  buffer combinations skipped, with the original numerical gates unchanged.
- The actual non-debug APK updated 0.6.5 on the API 36 ARM64/16KiB emulator;
  encrypted permanent history, a no-copy SAF model and local generation survived.
- Updated RU/EN store copy, real UI screenshots and the certificate-pinned F-Droid
  recipe. **No F-Droid submission or official server acceptance is claimed.**

Model weights, inference code, numerical patches and generation defaults are
unchanged. This is a packaging release, with no newly measured throughput gain.
Physical main-model/device qualifications retain their previous artifact hashes
and limits; large-context processing can remain slow. This is an early preview.
See [features and measured limits](https://github.com/gordeev/llamur).

## Русский

Linux-релиз с двумя независимыми чистыми сборками: unsigned APK совпали побайтово,
подпись проверена с обоими. Сертификат прежний — с публичной 0.6.5 можно обновиться
поверх, сохранив данные. Веса и код инференса не менялись. На 16 KiB эмуляторе
проверены обычное обновление, сохранение постоянного диалога и доступа к модели
без копирования, затем настоящий локальный ответ. Нужны Android 9+ и ARM64.
Для F-Droid рецепт подготовлен, заявка не отправлялась. Другие телефоны и новые
скоростные показатели этим релизом не заявляются.
