# llamur 0.6.5 — First public preview

Download **llamur-0.6.5-arm64-v8a.apk** from Assets below and open it on your phone.
Requires **Android 9+ and a 64-bit ARM64 OS**. Model weights are downloaded separately.

## Included

- Local GGUF chat with the patched llama.cpp CPU runtime; original weights and F16 KV preserved.
- Messenger-style chats, folders, search, pins, light/dark themes and English/Russian UI.
- Temporary chats by default; encrypted permanent history and optional auto-delete.
- Background completion notifications; manual context compaction and opt-in automatic compaction.
- Hugging Face downloads/import and external OpenRouter/OpenAI/Claude/compatible providers.
- OpenAI-compatible local API for tools such as Aider; authenticated loopback and Wi-Fi TLS.

## Installation and verification

Assets include the APK, **SHA256SUMS** and **SIGNING-CERTIFICATE.txt**.
This first public APK uses a dedicated release certificate. Earlier local test
builds used another signer and cannot be updated in place with this APK. Keep
any existing installation containing data you need. Future F-Droid builds may
also use a separate signer. See [signing and update channels](https://github.com/gordeev/llamur/blob/v0.6.5/docs/signing.md).

## Validation and limits

The published non-debug APK passed signature/ABI/ELF16KiB/notice/permission
checks and a clean install/launch/About check on the API36 ARM64/16KiB emulator.
The matching debug build passed1686 UI/localization checks; Python80 tests passed.
All14 native libraries are identical to the previously qualified engine.

Physical main-model tests were on Motorola Edge40Pro, Snapdragon8Gen2,12GB,
Android16, with Ornith1.5 9B Q4_K_M and Gemma4 E4B-it Q4_K_M. Other devices/models
are not certified. CPU4/4K are conservative defaults. Large contexts are slow;
experimental packing and prefix caching are off by default. No universal
speedup, arbitrary long-context quality or production-stability guarantee is implied.
[Measurements and scope](https://github.com/gordeev/llamur#measured-performance).
