# llamur 0.6.7 — Chat continuation and editable summaries

Download **llamur-0.6.7-arm64-v8a.apk** from Assets. Requires **Android 9+ and an ARM64 OS**. Uses the same release certificate as 0.6.5/0.6.6; update in place without uninstalling. Temporary RAM-only chats follow their existing lifetime policy when Android restarts the app.

## Changes

- Continue the same API chat after Stop, a connection interruption or a reasoning-only output-limit response. Visible partial text stays in history; incomplete signed/encrypted reasoning is not replayed as a completed answer.
- Edit and copy an entire summary, both before applying it and while it is active. Original messages follow the chat retention policy; Undo compaction restores the original context. Editing active memory invalidates opaque reasoning from its previous context epoch.
- Change the **response limit for an existing API chat** from the model card. `0` inherits the connection setting. The actual limit is displayed consistently in the card and composer.
- Explain that the per-request output budget can include thinking as well as visible text. No automatic paid retries or silent budget increase.
- Rename the compaction setting to **Save context limit** and explain its use for compaction estimates. It does not enlarge the provider model context or enable chat-history storage.
- English/Russian UI and light/dark themes retained.

## Verification and limits

Linux release+lint passed. 81 Python tests, 131 API checks in each theme and 59 compaction checks passed on the API36 ARM64/16KiB emulator. The actual signed release updated 0.6.6 on the emulator and was installed on the owner's phone; installed APK bytes and certificate were verified. No uninstall or app-data reset was used.

All **14 native libraries are byte-identical to 0.6.6**. Weights, inference kernels and numerical patches are unchanged. This update makes no new throughput or main-model quality claim. Cloud protocol/cancellation fixtures use a local test server; successful paid DeepSeek/OpenRouter account inference was not retested. Agent tool execution is not included.

APK packaging, permissions, notices, ELF16KiB/alignment and current F-Droid binary-signature scans passed. This is one Linux build with existing caches and an incremental correction, **not a new two-clean-build reproducibility claim**. Official F-Droid build-server comparison/inclusion is pending.
