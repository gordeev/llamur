# llamur — локальные модели на Android

Состояние на26октября2026: текущая0.6.4-dev добавляет внешних провайдеров, вложения,
сводки контекста, русский/английский UI и интерфейс диалогов к замороженному локальному кандидату0.1.0-dev.
[Приёмка локального baseline](../bench/release-acceptance-20261026.json)
не заменяет проверки новой версии; актуальные отчёты — [progress](progress.md).
Публичной публикации ещё нет. llamur запускает GGUF локально через
собственный Android runtime на базе закреплённого llama.cpp/GGML. После получения
модели компьютер, root, Termux и облачный аккаунт для чата не нужны.

## Интерфейс и источники

Главный экран — список диалогов, поиск, папки и нижние вкладки «Диалоги»,
«Локальный API», «Настройки». Синий + справа внизу создаёт пустой диалог;
пользователь выбирает активную модель и временный/постоянный режим. В чате есть
поиск и закреплённые сообщения.
В настройках добавляются GGUF/HF и [провайдеры по API](providers.md), активируются
нужные модели. Enter/стрелка справа отправляют, Shift+Enter добавляет строку,
во время запроса стрелка становится квадратом Stop. Светлая/тёмная/системная тема.

Меню диалога → «Контекст и сжатие»: ручная сводка с просмотром/применением и
отменой. Автокомпакт включается отдельно в настройках и по умолчанию выключен.
Исходная история сохраняется по режиму чата. Сводка меняет рабочий ввод модели,
может упустить детали и для API требует дополнительных запросов по тарифу
провайдера. Подробнее: [сжатие контекста](providers.md#сжатие-контекста-локально-и-по-api).

Поддержаны текстовые протоколы OpenRouter/совместимого Chat, OpenAI Chat/Responses,
Anthropic Messages; HTTPS или явно подтверждённый HTTP endpoint, ключ, каталог/model ID, параметры,
лимит ответа, streaming, Stop и фон. Credentials изолированы от входящего API.
Протокольные fixtures и реальный UI проверены на Motorola/эмуляторе; реальный
облачный аккаунт/платная генерация без ключа владельца не проверялись. Локальные
веса не изменялись. Ресурсы для удалённой модели предоставляет выбранный сервер;
локальные ограничения RAM/контекста ниже относятся к запуску GGUF.

## Требования

| Параметр | Требование и предел проверки |
| --- | --- |
| ОС и процессор | Android 9 / API 28+, 64-битная ARM64 ОС. Нижняя граница сборки; все версии Android физически не проверялись |
| RAM | Для проверенных 4,64–5,38 ГиБ моделей использовался телефон с 12 ГБ RAM (Android сообщает 11,03 ГиБ). Для 6/8 ГБ гарантий нет. Нужны также KV/state, workspace и запас Android |
| Накопитель | Gemma 4 977 171 584 байта; Ornith 5 780 090 816 байт. Вместе около 10,02 ГиБ. При независимом импорте исходник сохраняется до отдельного решения пользователя |
| Вычисления | Продуктовый CPU4, ARM64 runtime dispatch, исходные веса и F16 KV, native mmap без полного prefault. GPU/DSP не включены в принятый профиль |
| Контекст | Фиксированные точки 2/4/8/16/32K, отдельный резерв ответа; вход, шаблон и ответ делят общий бюджет. По умолчанию 4K. Переполнение — явная ошибка, вход не обрезается |
| 16K | Обе модели завершили один заполненный retrieval-контроль с точным ответом/EOS, с явно включённым bounded packing (default OFF). Это медленный экспериментальный режим: prefill Ornith 35,3 мин, Gemma 27,1 мин. Не доказательство качества любых длинных диалогов |
| 32K | Ornith: 32 256 входных +102 выходных/EOS, точный retrieval; prefill101,5мин, decode101с, PSS5,94ГиБ. Experimental packingON, cacheOFF. Gemma: 32 256+27/EOS, точный retrieval; prefill76,4мин, decode21с, PSS4,73ГиБ. Это не интерактивный режим или гарантия любых задач |
| Ответ | Искусственного потолка 1024 токена нет. Резерв ограничивается свободным контекстом и ресурсами; thinking тоже расходует токены |
| Страницы памяти | Физический Motorola: 4 КиБ; ARM64 Android16 эмулятор: реальные 16 КиБ. Эмулятор подтверждает совместимость, не скорость другого телефона |
| Сеть | Локальный чат offline. HF требует Интернет; сетевой API включается отдельно и после перезапуска выключен |

| **ARM64 Android16 эмулятор** | API36, страницы 16 КиБ | Lifecycle/IPC/overflow, 30 циклов, временные чаты, UI отправка, фоновый ответ, нажатие уведомления и запрет уведомлений, HF и хранилище. Не физический второй телефон |

Заводские характеристики Motorola: [спецификация производителя](https://es-latam.support.motorola.com/app/answers/detail/a_id/176754/~/especificaciones---motorola-edge-40-pro).
Android16 и результаты llamur взяты из собственных измерений.

Кандидаты по близкой платформе: OnePlus11 **16 ГБ** ([спецификация](https://www.oneplus.in/11/specs))
и Sony Xperia1V **12 ГБ** ([спецификация](https://www.sony.com/electronics/support/mobile-phones-tablets-mobile-phones/xperia-1-v-256gb/specifications)).
Они **не тестировались**, это не рекомендации к покупке. MediaTek/Exynos и другие
ARM64 SoC архитектурно возможны через CPU, но проверенной совместимости ещё нет.
Охлаждение, прошивка и лимиты памяти важнее одного названия процессора.

Основной интерфейс, настройки, импорт/HF, уведомления и сообщения об ошибках
доступны на русском и английском. Выбор: Настройки → Язык приложения → Как в системе,
Русский или English. На Android13+ доступен также системный выбор языка приложения;
на Android9–12 используется настройка внутри приложения. Неподдержанный системный
язык получает английский интерфейс. Испанский/немецкий пока не объявлены.
Названия моделей, сообщения пользователя, ответы модели и технические данные
диагностики не переводятся. Переключение языка не меняет исходный ввод модели.
Полная сертификация accessibility и всех версий Android/устройств не заявлена.

## Функции приложения

- Главный экран со списком диалогов, поиском по названию/модели/последней реплике,
  папками и нижними вкладками Диалоги / Локальный API / Настройки. Новый чат:
  активная модель, временный/постоянный, папка. Отдельный чат: Назад, поиск по
  сообщениям, закрепления с переходом, карточка модели local/API и сообщённые
  провайдером usage/cost (без выдуманной цены), пузырьки, Send/Stop, Enter.
- Временные многоходовые диалоги в RAM не записываются. По умолчанию «Никогда
  не сохранять». Постоянные — только по явному выбору, AES-GCM/AndroidKeyStore,
  черновики и закрепления, Keep либо автоудаление 1ч/24ч/7д/30д. Есть предупреждение
  ошибки сохранения; незавершённый запрос после перезапуска не повторяется.
  Автоочистка Android может задержаться. Раздельные reasoning/ответ и блоки кода.
- Светлая/тёмная/системная тема, выбор модели, настройки контекста, резерва ответа,
  thinking/температуры, точный подсчёт токенов до отправки и явные ошибки бюджета.
- Генерация принадлежит foreground service и продолжается при сворачивании.
  По завершении — уведомление «Ответ готов» без текста запроса; нажатие открывает
  нужный живой диалог. При запрете уведомлений ответ доступен после возврата.
  Системный Doze/OEM может приостанавливать работу: гарантии обхода ограничений нет.
- Одиночный GGUF (split/shards пока не поддержаны) через системный выбор файла: независимый импорт либо подключение без копии
  при постоянном доступе к обычному seekable файлу. SHA-256 и структура проверяются;
  перед загрузкой источник проверяется повторно. Подключённый файл нельзя перемещать
  или менять. Отключение ссылки не удаляет исходник.
- Новые загрузки/импорты идут в **Downloads / llamur / Models** на Android10+;
  на Android9 — приватное хранилище. Дубликат по SHA не создаётся. После импорта
  можно отдельно согласиться удалить исходник; перед удалением SHA проверяется снова.
- Hugging Face: repo/файл/revision, предварительные размер/лицензия, публичная
  загрузка без токена либо необязательный HF token по правам пользователя,
  прогресс, отмена, продолжение и проверка immutable revision/размера/SHA.
  Опционально токен хранится за AndroidKeyStore AES-GCM; его можно забыть.
- **OpenAI-compatible API**: `/v1/models`, `/v1/chat/completions`, stream/non-stream,
  stop/usage, отмена и явные ошибки. Один engine/одна модель с UI, занятый engine
  возвращает429. Loopback HTTP + Bearer; Wi-Fi LAN — TLS + Bearer и проверяемый
  сертификат. API выключен по умолчанию. Инструкция: [api.md](api.md).
- Aider0.86.2 выполнил две реальные правки через Ornith на телефоне; проверки кода
  прошли. Это работоспособность, **не интерактивная скорость**: ранний Wi-Fi контроль около110 и617с; финальный USB/TLS повтор156 и651с.
  Это разные зафиксированные прогоны, не сравнение ускорения.
  Tools/images/JSON-schema не заявлены; неподдержанные параметры отклоняются.
- Диагностика, управление местом и выгрузкой модели; никаких bundled-моделей,
  телеметрии, Play Services и скачиваемого исполняемого движка.

Реальный вход в gated/private HF с действительным пользовательским токеном ещё
не проверялся: такой токен не предоставлен. Проверены публичная HTTPS-загрузка,
resume/cancel и шифрованное хранение/удаление тестового credential.

## Что оптимизировано в инференсе

**Веса не дообучаются и не переквантизируются.** Закреплены исходные GGUF, tokenizer,
chat template и SHA в [models.lock.json](../bench/models.lock.json). Неизменность
файла дополняется численными и модельными проверками: сама по себе она недостаточна.
Upstream `701fd25b3a55a90297dec0d925204b29084054c8` сохранён чистым;
изменения оформлены [patch series](../patches/cpu-numeric/series.json).

| Работа | Результат |
| --- | --- |
| F32 attention и scalar/recurrent arithmetic | Исправлены исследованные промежуточные округления и расхождения. F16 KV сохранён |
| Длинный attention | При >8192 ключах локальное F64-накопление исправляет ошибку длинной суммы; короткие контроли побитно сохранены. Это точность, не ускорение |
| Decode reproducibility | Фиксированное разбиение сумм не меняется с числом workers; thread/affinity pools освобождаются и маска восстанавливается |
| Native mmap/no-prefault | Снижает исследованные пики памяти/страничное давление; долгий prefill остаётся. Нет обещания ускорения от mmap |
| Ограниченная lossless упаковка prefill | Экспериментальный scratch до81МиБ, без второй постоянной копии весов. В старой пяти-парной серии Ornith512:82,58→49,57с (1,65×); это ограниченный результат того APK/профиля, не общая скорость приложения |
| RAM prefix cache | По умолчанию OFF; явный бюджет64–256МиБ, контекст≤8K и проверенные две модели. Exact KV/recurrent snapshot, namespace сессии, отмена/выгрузка. В отдельных1K-контролях prefix hit Ornith4,82с/Gemma1,49с; не универсальный speedup |
| Threads/backend screening | Проверены1–7 workers и affinity; устойчивое преимущество7 не принято, default4. Vulkan OEM compiler crash и OpenCL NLL-регрессия исключили эти кандидаты |
| Ограничения представления | KleidiAI extra weight conversion и OpenCL BF16→F16 запрещены. Полный/Q4 Ornith repack и compact SWA Gemma отклонены после memory/quality failures |
| Android pipeline | Отдельный процесс, отмена prefill/decode, memory/thermal admission, framed SHA IPC, инкрементальный UI без повторной сериализации всей истории на каждый токен |

Общий CPU packing/загрузка применимы к разным архитектурам, но Ornith здесь —
конкретный **qwen35**: recurrent state отличается от **gemma4** sliding/shared-KV.
Проверка Ornith не сертифицирует автоматически всё семейство Qwen, другие GGUF
или кванты. Специфичные пути Gemma проверяются отдельно.

Результаты и ограничения: [performance.md](performance.md),
[progress.md](progress.md).
Подготовка F-Droid не означает принятия каталогом; публикация не выполнялась.
Управление телефоном через дополнительные разрешения — отдельная будущая работа.

Подключения к OpenRouter/OpenAI/Claude и другим внешним endpoints запланированы
отдельно в M9; текущий APK их не вызывает.
