<p>Текстовые языковые модели работают прямо на телефоне. Выберите совместимый одиночный GGUF или загрузите файл с Hugging Face. Модели не входят в приложение.</p>
<ul>
<li>Главный экран со списком диалогов, поиском и папками; вкладки Диалоги / Локальный API / Настройки. Выбор модели, поиск и закрепления в чате, отправка/стоп.</li>
<li>Необязательные подключения OpenRouter/OpenAI/Claude или своего совместимого HTTPS API: streaming, каталог моделей, параметры и зашифрованное сохранение ключа по выбору.</li>
<li>Список диалогов, поиск и папки, отдельный чат с закреплениями и карточкой модели. Временные или постоянные диалоги по выбору.</li>
<li>Генерация в фоне и уведомление «Ответ готов», открывающее живой диалог.</li>
<li>Профили моделей, фиксированные точки контекста, отдельный резерв ответа, явное переполнение и светлая/тёмная тема.</li>
<li>Проверенные импорты, подключение файлов без копии при постоянном доступе, продолжение HF-загрузок и необязательное шифрованное хранение токена.</li>
<li>OpenAI-совместимый HTTP/SSE API через тот же engine. Для LAN обязательны TLS и Bearer token; локальный loopback также защищён токеном.</li>
</ul>
<p>По умолчанию переписки временные и не записываются. Постоянные сохраняются только по явному выбору, зашифрованно с AndroidKeyStore; доступны автоудаление и отключение хранения. Android может задержать фоновую очистку. Энергосбережение Android может приостановить работу в фоне. CPU сохраняет исходные веса выбранной модели; экспериментальные GPU-пути в этой сборке выключены.</p>
<p>Нужны Android9+ и64-битная ARM64 ОС. Физически проверен Motorola Edge40Pro с12ГБ RAM и двумя закреплёнными моделями. Другие устройства и произвольные GGUF пока не гарантированы. Большой контекст может обрабатываться десятки минут;16K экспериментален, статус32K смотрите в результатах версии.</p>
<p>Нет телеметрии, обязательного аккаунта, Play Services и root. После получения GGUF компьютер и Интернет для локального чата не нужны. Удалённый диалог передаётся явно выбранному провайдеру с его условиями и лимитами. Сеть используется для загрузок по запросу и отдельно включённого API. Лицензии и права доступа моделей проверяются отдельно.</p>
